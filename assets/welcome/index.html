Features

Everything you need. Nothing you don't.

Kodemo ships with the essentials — all of them native, all of them fast, all of them offline.

Cross-platform

One native experience on Linux, Windows and macOS. Same editor, same shortcuts, same extension surface.

Native Rust

Single binary. No Electron. No runtime. Boots in milliseconds on any of the three platforms.

Ghost Autocomplete

Local Qwen 0.5B via llama.cpp. Private by default, offline by design.

Built-in WebView

Live-preview HTML, CSS and JS without leaving the editor.

VS Code Themes

Import your favorite color theme as JSON. Dark+ and Light+ built in.

Bilingual

English and Brazilian Portuguese, out of the box. Instant switching.

Legacy GPU Support

Runs on old hardware — from OpenGL 2.0 GPUs to modern ones, with automatic software fallback.

Energy Saver

Adaptive throttling for CPU, AI, and WebView that gives your battery back.

Auto-scaffold

Empty file? Get working boilerplate immediately. Undo with Ctrl+Z.

Why Kodemo

Lean. Private. Provable.

Kodemo uses less RAM than Electron-based editors and sends no data to any server. You don't have to trust us — every line is open source and auditable.

  • Native Rust binary — significantly lighter on RAM than Electron-based IDEs.
  • Zero telemetry, zero analytics, zero phone-home on every platform.
  • Verify yourself: the full source code is public and licensed under MIT/Apache-2.0.

use eframe::egui;
use kodemo::{App, Config};

fn main() -> eframe::Result<()> {
    let cfg = Config::load();

    eframe::run_native(
        "Kodemo",
        cfg.native_options(),
        Box::new(|_cc| {
            Box::new(App::new(cfg))
        }),
    )
}

The Kodemo mascot

Meet Kodemi.

Kodemi is Kodemo's chibi e-girl mascot. Thick black nerd glasses, dark messy hair with blue, green and purple streaks, an oversized black hoodie, and knee-high black Converse boots. She reviews your diff before you commit, never sends your code anywhere, and runs on caffeine and compile errors.

  • Thick black nerd glasses — she reads your stack traces for fun.
  • Dark messy hair with blue, green and purple streaks — the brand, in hair form.
  • Oversized black hoodie — because hoodie weather is all weather.
  • Knee-high black Converse — always ready for a refactor.
Local AI

Ghost autocomplete. No cloud. No API keys.

Powered by Qwen 0.5B running on llama.cpp — entirely on your machine. Your code never leaves your computer. The model loads on first request, and unloads after five minutes of inactivity.

  • Private by default — no telemetry, no network requests.
  • Runs on CPU or GPU on Linux, Windows and macOS.
  • Toggle per project or per session. Never forced on.

Auto-scaffold

Zero-keystroke scaffolding.

Create an empty file in a supported language and Kodemo fills in idiomatic boilerplate. Undo it with Ctrl+Z, or disable it per language in one click.

HTML, Rust, Python, Go, C, C++, Shell, Markdown and more — and !axum, !react, !fastapi scaffold whole projects.
